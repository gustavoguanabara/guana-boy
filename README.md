## 🎮 Controles

### 💻 No Computador (Teclado)
- **Espaço / Seta para Cima:** Pular (mantenha pressionado para pulo mais alto).
- **Enter / Botão START:** Iniciar partida, pausar ou reiniciar.
- **P ou Escape:** Pausar / Despausar.
- **M ou Botão SELECT:** Ligar / Desligar áudio.
- **Z:** Alternar Zoom dinâmico no visor LCD.

### 📱 No Celular / Tablet (Touchscreen)
- **Toque Direto no Visor LCD:** Pule tocando diretamente na pequena tela do jogo!
- **Botões Virtuais A e B:** Pular com feedback luminoso neon e micro-vibração tátil.
- **D-Pad (Cima):** Pular.
- **Menu Inferior Retrô (Gaveta "MENU"):**
  - ▶ / ⏸ **Play & Pause:** Iniciar, pausar e retomar a partida.
  - 🔍 **Zoom:** Ampliar o visor LCD em 1.75x na tela.
  - 🔊 **Som:** Alternar áudio chiptune.
  - 🔄 **Reiniciar:** Reiniciar partida instantaneamente.
  - 🏆 **Limpar Recorde:** Zerar recorde salvo no navegador (com confirmação).

## 🌟 Principais Recursos

- **Proporção Real 941:1672 Sem Distorção:** Encaixe matemático milimétrico em qualquer tela (smartphones em pé ou deitados, tablets e monitores ultra-wide).
- **Visor LCD Calibrado em 320x278:** Aspect ratio fiel sem estiramento ou achatamento de sprites.
- **Áudio Chiptune 8-bit Procedural:** Sintetizado em tempo real via Web Audio API (zero arquivos de áudio pesados).
- **Feedback Háptico Realista:** Sensação física de clique nos botões e vibração em saltos e impactos via Vibration API.
- **Multi-Touch Completo:** Permite jogar com múltiplos dedos simultâneos sem travamento de pulo.
- **Persistência de Recorde:** High score salvo localmente via Web Storage API (`localStorage`).
- **Zero Dependências:** Código limpo, leve e de inicialização ultrarrápida.
